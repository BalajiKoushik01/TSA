## 📊 Project Highlights

### Methodology
- **Model**: SARIMA (Seasonal AutoRegressive Integrated Moving Average)
- **Smoothing**: Holt-Winters Triple Exponential Smoothing
- **Validation**: ADF Test, ACF/PACF Analysis, Residual Diagnostics

### Key Findings
- **Forecast**: ₹5200/qtl in October 2026
- **Confidence Interval**: Upper bound ₹7000/qtl (95% CI)
- **Seasonality**: Strong Oct-Nov spike pattern identified
- **Model Performance**: Robust residuals, validated stationarity

### Visualizations Include
- Time series decomposition
- Smoothing technique comparisons
- ACF/PACF plots
- Model diagnostics
- Forecast with confidence intervals
- 3D volatility topology
- Phase space analysis
